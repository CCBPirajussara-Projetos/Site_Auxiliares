# Site_Auxiliares
Sistema web desenvolvido para auxiliar os Auxiliares de Jovens nas reuniões, com funcionalidades de contagem de frequência, gerenciamento de rodízios e geração de recitativos para envio antecipado pelo celular, gerar estatísticas anuais das reuniões de jovens, facilitando o acompanhamento da participação e dos resultados ao longo do ano.
