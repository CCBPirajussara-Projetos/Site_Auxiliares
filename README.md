# Automatização Auxiliares CCB do Pirajussara

## Description
Sistema web desenvolvido para auxiliar os Auxiliares de Jovens nas reuniões, com funcionalidades de contagem de frequência, gerenciamento de rodízios e geração de recitativos para envio antecipado pelo celular, gerar estatísticas anuais das reuniões de jovens, facilitando o acompanhamento da participação e dos resultados ao longo do ano.
**Os recitativos online não substituem os recitativos físicos, é apenas uma alternativa rápida e prática de distribuir os recitativos na sua fila, pelo Whatsapp, ou o meio de comunicação que preferir, sem desperdiçar papel, com o auxiliar precisando entregar o recitativo apenas no dia do culto.**
